## ADDED Requirements

### Requirement: 背景移除的錯誤訊息只在背景移除工具底下顯示，不隨工具切換殘留

背景移除失敗時顯示的錯誤訊息 SHALL 只在使用者停留在「背景移除」工具（`tool === 'remove'`）時顯示，使用者切換到其他工具（加入物件、文字、裁切）後 SHALL NOT 繼續顯示上一次背景移除失敗的錯誤訊息。

#### Scenario: 背景移除失敗後切換到其他工具，錯誤訊息不再顯示

- **WHEN** 使用者嘗試背景移除失敗（例如飼料不足），畫面顯示錯誤訊息，接著切換到「加入物件」或「文字」工具
- **THEN** 錯誤訊息 SHALL 不再顯示於畫面上

##### Example: 背景移除失敗後依序切到物件、文字工具

- **GIVEN** 使用者以飼料餘額為 0 的帳號嘗試「背景移除」，畫面顯示「生成失敗，請再試一次」
- **WHEN** 使用者依序點擊「加入物件」工具、再點擊「文字」工具
- **THEN** 在「加入物件」與「文字」工具底下皆看不到「生成失敗，請再試一次」這則訊息

#### Scenario: 切回背景移除工具後，錯誤提示行為維持正確

- **WHEN** 使用者從其他工具切回「背景移除」工具，再次嘗試背景移除並再次失敗
- **THEN** 錯誤訊息 SHALL 重新顯示於背景移除工具底下
