## ADDED Requirements

### Requirement: 選擇輸出內容類型

設定區 SHALL 在「1. 選擇商品圖片」之前提供「要產出什麼」分段選擇器，讓使用者於生成前選擇輸出內容類型：「文案＋配圖」（預設，5 顆飼料）、「只要文案」（2 顆飼料）、「只要配圖」（3 顆飼料），並在選擇器下方顯示提示文字「分開產出的好處：之後只重做其中一項，不必兩項都重扣。」。

#### Scenario: 使用者檢視要產出什麼區塊

- **WHEN** 使用者檢視設定區頂部「要產出什麼」區塊
- **THEN** 顯示三個分段選項（各自標示名稱與飼料顆數）與提示文字「分開產出的好處：之後只重做其中一項，不必兩項都重扣。」，且「文案＋配圖」為預設選取狀態

##### Example: 三個選項與對應飼料顆數

| 選項     | 飼料顆數 |
| -------- | -------- |
| 文案＋配圖（預設） | 5 顆     |
| 只要文案 | 2 顆     |
| 只要配圖 | 3 顆     |

#### Scenario: 使用者選取其他輸出類型

- **WHEN** 使用者點選「只要文案」或「只要配圖」分段選項
- **THEN** 該選項顯示為選取狀態（原選取的選項取消選取），且後續點擊「產生貼文」時以該輸出類型呼叫生成

## MODIFIED Requirements

### Requirement: 生成貼文標示飼料消耗

設定區底部 SHALL 依所選輸出類型顯示對應的預估飼料消耗（文案＋配圖 5 顆／只要文案 2 顆／只要配圖 3 顆），並提供「產生貼文」動作。

#### Scenario: 使用者檢視生成區

- **WHEN** 使用者檢視設定區底部，且尚未變更預設輸出類型「文案＋配圖」
- **THEN** 顯示「預估消耗 5 顆飼料」與帶加號圖示的「產生貼文」按鈕

#### Scenario: 使用者切換輸出類型後預估消耗隨之更新

- **WHEN** 使用者於「要產出什麼」選取「只要文案」
- **THEN** 設定區底部「預估消耗」立即改為顯示「預估消耗 2 顆飼料」

##### Example: 三種輸出類型對應的預估消耗顯示

| 選取的輸出類型 | 預估消耗顯示   |
| -------------- | -------------- |
| 文案＋配圖     | 預估消耗 5 顆飼料 |
| 只要文案       | 預估消耗 2 顆飼料 |
| 只要配圖       | 預估消耗 3 顆飼料 |

### Requirement: 結果區呈現圖與文案兩欄

生成後 SHALL 依所選輸出類型呈現結果：選取「文案＋配圖」時以左右兩欄呈現，左欄為貼圖（比例吃輸出比例）與「換一張圖／下載」動作，右欄為文案與「複製文案／重寫文案」動作；選取「只要文案」時只呈現文案欄；選取「只要配圖」時只呈現貼圖欄。

#### Scenario: 首次進入尚無生成結果

- **WHEN** 使用者首次進入 MV-03 且尚未完成生成
- **THEN** 結果區顯示空狀態提示，不預先偽造完成後圖片與文案

#### Scenario: 使用者複製文案

- **WHEN** 使用者點擊「複製文案」
- **THEN** 文案與 hashtag 一併複製到剪貼簿，按鈕顯示「已複製」

#### Scenario: 選取只要文案時僅呈現文案欄

- **WHEN** 使用者選取「只要文案」並完成生成
- **THEN** 結果區只顯示文案欄與「複製文案／重寫文案」動作，不顯示貼圖欄

#### Scenario: 選取只要配圖時僅呈現貼圖欄

- **WHEN** 使用者選取「只要配圖」並完成生成
- **THEN** 結果區只顯示貼圖欄與「換一張圖／下載」動作，不顯示文案欄
