## ADDED Requirements

### Requirement: 儲存設定成功時提供明顯的視覺回饋

品牌設定頁存檔成功後，SHALL 在畫面右下角顯示一張卡片式 toast 提示（圖示＋標題＋訊息），並在數秒後自動消失；使用者 SHALL 也能主動點擊關閉按鈕提前關閉。SHALL NOT 只依賴容易被忽略的行內小字作為唯一的完成回饋。

#### Scenario: 使用者存檔成功後看到 toast 提示

- **WHEN** 使用者在品牌設定頁編輯欄位後按下「儲存設定」，且存檔請求成功
- **THEN** 畫面右下角浮出 toast 卡片，內容包含成功圖示、標題與訊息文字，數秒後自動消失

##### Example:

- **GIVEN** 使用者在「品牌基本資料」分頁修改了「官方網站」欄位
- **WHEN** 使用者按下「儲存設定」，`PUT /brand` 回應成功
- **THEN** 畫面右下角出現 toast，標題顯示「已儲存」、訊息顯示「品牌設定已成功更新」，6 秒後自動消失

#### Scenario: 使用者手動關閉 toast

- **WHEN** toast 顯示中，使用者點擊 toast 上的關閉按鈕
- **THEN** toast 立即消失，不需等待自動消失的時間

#### Scenario: 存檔失敗時不顯示這個成功 toast

- **WHEN** 使用者按下「儲存設定」，但存檔請求失敗
- **THEN** 不顯示這個成功提示 toast，畫面維持既有的失敗處理方式
