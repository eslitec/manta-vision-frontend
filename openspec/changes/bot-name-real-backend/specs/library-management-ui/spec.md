## MODIFIED Requirements

### Requirement: 頁面標示所屬機器人情境

圖庫管理中心 SHALL 顯示提示文字，說明目前圖庫隸屬於哪個機器人，切換機器人會顯示該機器人專屬的素材。提示文字與圖片選擇器的副標 SHALL 帶入目前機器人的實際名稱（與側欄相同的名稱優先序：品牌設定名稱 → 機器人名稱 → 預設字串），SHALL NOT 寫死示範名稱。

#### Scenario: 使用者進入圖庫管理中心

- **WHEN** 使用者導覽到圖庫頁面（`/library`），目前機器人名稱解析為「春日選品」
- **THEN** 頁面頂端顯示「此圖庫隸屬於機器人「春日選品」。切換機器人會顯示該機器人專屬的素材與生成產物。」

#### Scenario: 開啟圖片選擇器

- **WHEN** 使用者在任一生成工具開啟「從圖庫選擇」對話框，目前機器人名稱解析為「春日選品」
- **THEN** 對話框副標顯示「隸屬機器人「春日選品」的素材與生成產物」
