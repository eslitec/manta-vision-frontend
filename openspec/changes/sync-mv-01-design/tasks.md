## 3. 排查使用者回報的按鈕點擊位移問題（跨頁面的技術問題，不是單一頁面的視覺落差）

- [x] 3.1 使用者回報「按儲存設定／永久刪除按鈕時，按鈕本身會位移」。排查後排除兩個懷疑方向：(a) 儲存按鈕文字在 `儲存設定`／`儲存中…` 之間切換造成寬度變化——實測兩者文字寬度相同（56px），非成因；(b) `DialogButton` 的 `--plain`／`--primary`／`--danger` 三個變體高度不一致（`--plain` 有 `1px` 邊框、其他兩個沒有，實測差 `1.6px`）——這個高度差異是真的存在，但跟「點擊時位移」的描述不完全對得上（這是靜態的變體間差異，不是點擊瞬間發生的事）
- [x] 3.2 真正找到的成因：Firefox 會在 `<button>` 內部加一層看不見的 `-moz-focus-inner` 邊框＋padding，沒有清掉的話，點擊按鈕時文字會跟著這層看不見的邊框位移 1-2px，Chrome／Edge 不會有這個現象（這也是為什麼用 Playwright/Chromium 自動化測試量不出位移——問題本身就是 Firefox 特有的）。在全站共用的 `src/assets/scss/main.scss` 補上 `button::-moz-focus-inner { border: 0; padding: 0; }`，這是業界慣用的正規化寫法，一次修正全站所有按鈕，不是只修儲存／刪除這兩顆
