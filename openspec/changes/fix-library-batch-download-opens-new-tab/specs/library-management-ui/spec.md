## ADDED Requirements

### Requirement: 批次下載素材真的觸發檔案下載，不是開新分頁

使用者在批次操作列點擊「下載」時，畫面 SHALL 對每一筆有真實網址的選取素材觸發瀏覽器的檔案下載，SHALL NOT 只是開啟新分頁顯示圖片。素材伺服器因為 CORS 限制導致無法讀取內容時，SHALL 退回開啟新分頁讓使用者至少能看到圖片，SHALL NOT 完全沒有反應。

#### Scenario: 點擊下載觸發真實檔案下載

- **WHEN** 使用者勾選一或多筆有真實網址的素材並點擊「下載」
- **THEN** 瀏覽器 SHALL 對每一筆素材各自觸發檔案下載，SHALL NOT 開新分頁顯示圖片

##### Example:

- **GIVEN** 使用者勾選了 2 筆已上傳的圖片素材
- **WHEN** 使用者點擊批次操作列的「下載」
- **THEN** 瀏覽器依序觸發 2 次檔案下載，下載的檔名對應各自的素材名稱，沒有分頁被開啟

#### Scenario: 素材伺服器無法讀取內容時退回開啟新分頁

- **WHEN** 素材伺服器沒有開放 CORS，導致讀取素材內容失敗
- **THEN** 畫面 SHALL 退回開啟新分頁顯示該筆素材，SHALL NOT 讓使用者完全看不到任何反應
