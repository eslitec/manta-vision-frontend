## ADDED Requirements

### Requirement: 編輯器的素材選擇彈窗使用專屬標題與副標

圖片編輯器開啟「從圖庫選擇」彈窗（`ImagePickerDialog`）時，SHALL 顯示標題「從圖庫選擇要編輯的素材」與副標「選擇後會載入畫布，原本的編輯內容會先提示是否儲存」，SHALL NOT 沿用其他頁面共用的通用副標文案。其他呼叫 `ImagePickerDialog` 的頁面（生成圖片、生成影片、行銷 PO 文、AI 試穿）SHALL 維持原本的通用副標，不受影響。

#### Scenario: 使用者從編輯器開啟素材選擇彈窗

- **WHEN** 使用者在圖片編輯器點擊「從圖庫選擇」
- **THEN** 彈窗標題顯示「從圖庫選擇要編輯的素材」，副標顯示「選擇後會載入畫布，原本的編輯內容會先提示是否儲存」

#### Scenario: 其他頁面的素材選擇彈窗維持通用副標

- **WHEN** 使用者在生成圖片、生成影片、行銷 PO 文或 AI 試穿頁面開啟「從圖庫選擇」彈窗
- **THEN** 彈窗副標維持原本隸屬機器人的通用文案，不受編輯器專屬副標影響
